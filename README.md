# Travel Booking Website

A full-stack travel booking platform. Customers can explore destinations, book travel packages and contact the agency online; administrators manage bookings, customer data and messages from a secure dashboard.

## Features

- User registration and secure login
- Travel package booking
- Reviews section for customer feedback
- Admin dashboard to manage packages, bookings and users
- Responsive interface

## Tech stack

- **Backend:** PHP, MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Docker, Docker Compose

## Run it

```bash
git clone https://github.com/Sepi-X/Travel-Website.git
cd Travel-Website
docker compose up --build
```

Then open the site in your browser on the port set in `docker-compose.yaml`.
